# Doc-citation error ceilings, enforced by check_baselines.py.
#
# Format:  <max_errors>  <scope>  [code]   # reason
#
# A scope that has been cleaned to a known count is recorded here so that it
# cannot silently un-clean itself. This is a RATCHET, not a target: when a
# scope improves, lower the number in the same commit that improves it. The
# checker tells you when a ceiling has gone slack.
#
# Raising a number is a decision, and the reason column is where it gets
# argued. "It went up" is not a reason.
#
# NOTE ON WHY THIS FILE EXISTS
# These ceilings were previously carried only in task briefs and prose --
# "docs/plan-netplay-connection.md must stay at 0", "src/netplay must stay at
# 11". A protection that lives in prose is protection that stops being true
# without telling anybody, which is the exact failure mode this whole
# documentation-hardening effort is about. So they are checked here instead.
#
# WHAT IS ENFORCED, AND WHY ONLY THIS  (task #117)
#
# Enforcement used to cover two broad scopes -- `src/netplay` for every finding
# code, and `<tree>` for unanchored-citation. Measured over one session, those
# two produced almost all of the repair work and almost none of the benefit:
# task #109 broke 19 citations, tasks #96/#104 repointed 267, task #94 left the
# two ceilings breached at 16 and 28, and one merge breached both and needed 60
# citations remapped -- all by hand, because `--fix` is banned (four measured
# defects, 55.6% of its suggestions wrong). Against that, tree-wide errors moved
# 1113 -> ~1091 across several dedicated lanes. Measured again here for the
# record: 1096 errors tree-wide at aa2c2bf1, 1095 after this commit's one
# repair, same pinned linter.
#
# Task #110 then adjudicated 186 of the cited targets: 102 were NEVER RIGHT,
# 37 repairable, 24 already correct. Most were wrong the day they were written
# -- several authored against a working tree the a752e2ca omnibus squash
# removed, with a uniform -4 save / -11 load / -1 header offset against
# anything that has ever been committed here. Repointing a number that was
# never true would manufacture a citation nobody ever verified.
#
# And task #82 found that all seven high-blast-radius operator documents were
# ALREADY at zero and had stayed there on their own.
#
# So the tax was falling on every code change while the errors sat in archived
# research documents that nobody follows. This file now enforces the documents
# a wrong line number actually misleads somebody through, and the one defect
# class where a wrong line number is expensive:
#
#   * the seven operator documents -- what somebody reads at 2am;
#   * plan documents under active work;
#   * unanchored-citation, the anchor-required rule that exists for
#     src/netplay/game_state.c.
#

# --- the anchor-required rule -----------------------------------------------
# tools/doc-citations/anchor-required.txt lists exactly one file,
# src/netplay/game_state.c, so an `unanchored-citation` finding can only ever
# be a bare `game_state.c:NNN` -- a line number into a 609-entry GS_SAVE/GS_LOAD
# table with nothing named to check it against. That is the highest-value
# single check here: a wrong line sends a desync investigation to the wrong
# member, and before task #110 the class was invisible.
#
# Scoped to `src`, `include` and `tools` -- which, with `docs/*.md` and the
# root `*.md`, is everything scan_targets() reads (check_doc_citations.py:1333)
# -- so it covers every citation written in code or tooling. Together with the
# eight document ceilings above, which are all-codes and so already forbid an
# unanchored citation, the rule holds over the whole live corpus. The only
# thing released is docs/*.md that is not one of the eight: the archive.
#
# WHAT THIS DELIBERATELY NO LONGER COVERS: the 19 remaining unanchored
# citations all live in research and plan documents that are dated historical
# records -- several correctly describe the tree their own commit replaced --
# rather than live pointers, and holding them at exactly 19 forced every
# unrelated lane to re-audit them. They are released on purpose.
#
# UPDATE 2026-08-30: three of the five documents that hold them
# (research-3sxtra-netplay-port.md, plan-netplay-port.md,
# plan-netplay-track-a.md) have since moved into docs/archive/, which is no
# longer scanned at all -- docs/archive/ is in SKIP_SCAN_DIRS, proven by
# check_archive_is_not_scanned() in test_doc_citations.py. So those citations
# are not merely un-ceilinged now, they are invisible.
#
# UPDATE 2026-09-02: plan-fcade-replay-browser.md has now moved there too, with
# the rest of the replay lineage's plan documents, as part of the replay
# descope -- the feature they planned was deleted, so they are historical
# records rather than live pointers. That leaves exactly ONE of the five in the
# live corpus: research-desync-deep-investigation.md, which
# rollback-determinism-harness.md still cites as its §A source. It is still
# scanned and still un-ceilinged.
# A NEW document placed in docs/ and not listed above is likewise not covered;
# that is the cost of the drop and it is recorded here rather than hidden.
